Disband

An open chat platform: servers, channels, direct messages, group chats, voice and video calls, and private notes — on web, desktop and iOS.

This site documents how Disband is built and how to work on it. It is written for two audiences: people running or contributing to the codebase, and developers who want to build on top of it.

Honest scope. These docs describe what Disband actually does today, at version 1.0.26. Where something is planned but not built — most importantly the bot API — it is labelled Planned and you will not find example code implying otherwise.

What Disband includes

AreaDetails
ServersChannels grouped into categories, roles with granular permissions, invites, bans, discovery.
MessagingChannel messages, DMs, group chats, replies, reactions, editing, attachments, polls, link previews.
Voice & video1:1 and group calls over WebRTC, with mute, deafen, camera and screen share.
NotesA private, owner-only space for text and media. No sharing path exists.
SubscriptionsFree, Basic and Super tiers via Stripe, gating upload size, video quality and themes.

Clients

ClientBuilt with
WebNext.js 16 (App Router, Turbopack), React 19, Tailwind CSS 4
DesktopTauri, wrapping the exported web build
iOSNative Swift and SwiftUI, with WebRTC for calls

All three talk to the same Supabase project, so a change made on one appears on the others through realtime.
