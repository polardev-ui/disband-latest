Data model

Every table lives in the public schema with Row Level Security enabled.

Identity

TablePurpose
profilesOne row per user, keyed to auth.users. Display name, username, avatar, banner, accent colours, status, theme, badge flags.
friendshipsRequester/addressee pair with status pending, accepted or blocked.
profile_change_logBacks per-plan rate limits on username and avatar changes.

Servers

TablePurpose
serversName, icon, banner, description, owner, invite code, discoverable flag.
server_membersMembership, with legacy role plus a role_id.
server_rolesNamed roles carrying a JSON permission set.
member_rolesMany-to-many assignment of roles to members.
channel_categoriesOrdered groupings for channels.
channelstext or voice, ordered by position. read_only marks announcement channels.
server_bansPer-server bans.

Messaging

TablePurpose
messagesChannel messages: content, attachment, reply target, edit timestamp.
dm_threads / dm_messages1:1 conversations. Threads are created only through an RPC.
group_chats / group_chat_members / group_messagesMulti-person chats outside any server.
message_reactionsEmoji reactions, keyed by context type so one table serves channels, DMs, groups and notes.
notesPrivate notes. Every policy is auth.uid() = user_id; there is no sharing path.

Presence, calls and platform

TablePurpose
voice_presenceWho is in which voice channel, with mute and deafen state.
group_call_presenceEquivalent for group calls.
notifications / device_tokensIn-app notifications and push registration.
platform_bans / signup_ip_blocks / audit_logPlatform moderation and an audit trail.
bug_reports / mobile_waitlist / media_postsSupporting product surfaces.

Conventions

  • Primary keys are uuid with gen_random_uuid().
  • Timestamps are timestamptz, defaulting to now().
  • Deletes cascade from the owning row — deleting a server removes its channels and messages.
  • Columns are snake_case; TypeScript and Swift models map them explicitly.
