# Bundled fonts

Both are used by the Super skins and are self-hosted rather than loaded from a
font CDN: the desktop app is an offline bundle, and the site's CSP allows no
third-party font host.

| File | Family | Used by | Licence |
| --- | --- | --- | --- |
| `press-start-2p-latin.woff2` | Press Start 2P — CodeMan38 | Minecraft skin | SIL Open Font License 1.1 |
| `oswald-600-latin.woff2` | Oswald — Vernon Adams et al. | Call of Duty skin | SIL Open Font License 1.1 |

Latin subsets only, which is what the skins render; the full families are
several times the size for glyphs no skin uses.

The SIL Open Font License permits bundling and redistribution with software.
Full text: https://openfontlicense.org
